# Product Thesis

DataForge helps data engineers investigate unexpected data behavior, collect evidence, test hypotheses, and turn the resulting fix into a reproducible engineering artifact.

## The Core Workflow

1. DATA PROBLEM
2. DETECT / OPEN
3. INVESTIGATE
4. COLLECT EVIDENCE
5. FORM HYPOTHESIS
6. TEST HYPOTHESIS
7. CONFIRM/REJECT
8. FIX
9. VALIDATE
10. REPRODUCIBLE ARTIFACT
11. CODE / TEST / PR

Everything we add must strengthen this loop. If a feature does not strengthen it, defer it.

## Actual Product Differentiation
DataForge is an **investigation-first data debugging environment**.
The important word is Investigation, not dataset, dashboard, rule, query, model, or AI agent.
