# Security & Trust Rules

## Product Trust Rules
1. Never silently modify user data.
2. Never silently delete data.
3. AI recommendations are recommendations.
4. Every important AI conclusion must show supporting evidence.
5. Every transformation must be reversible where practical.
6. Every exported fix must be reproducible.
7. Never claim certainty when the system only has a hypothesis.

## Local-first
Default processing is local. Data does not leave the user's machine unless explicitly configured. No mandatory cloud upload.
